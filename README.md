# ربات تلگرام مدیریت پیج اینستاگرام

ربات ویدیوهای پیج‌های اینستاگرام و کانال‌های یوتیوبی که بهش می‌دی رو دانلود می‌کنه، قبل از انتشار برات می‌فرسته تا تأیید کنی، و بعد با کپشن ثابت توی پیجت منتشر می‌کنه. استوری‌ها رو هم همین‌طور. ریلزی هم که از اکانت شخصیت به دایرکت پیج بفرستی خودش می‌ره توی صف انتشار.

ابزارهای اوپن‌سورس استفاده‌شده: [instagrapi](https://github.com/subzeroid/instagrapi)، [yt-dlp](https://github.com/yt-dlp/yt-dlp)، [python-telegram-bot](https://github.com/python-telegram-bot/python-telegram-bot)

> ⚠️ instagrapi غیررسمیه و خلاف قوانین اینستاگرام. ممکنه پیج قفل یا محدود بشه. آروم و طبیعی استفاده کن.

---

## راه‌اندازی روی Render (پلن رایگان)

پلن رایگان Render دیسک دائمی نداره و با هر ری‌استارت فایل‌ها پاک می‌شن، برای همین اطلاعات ربات (صف، پیج‌ها، سشن اینستاگرام) توی یه دیتابیس Supabase نگه داشته می‌شه. ویدیوهایی که پاک شده باشن موقع انتشار خودکار دوباره دانلود می‌شن.

### ۱. دیتابیس Supabase
1. توی supabase.com یه پروژه‌ی رایگان بساز و رمز دیتابیس رو یادداشت کن.
2. بالای صفحه بزن **Connect** و از بخش **Session pooler** آدرس اتصال (URI) رو کپی کن. شبیه این‌ه:
   `postgresql://postgres.xxxx:[YOUR-PASSWORD]@aws-0-xx.pooler.supabase.com:5432/postgres`
3. جای `[YOUR-PASSWORD]` رمز دیتابیس رو بذار. این می‌شه `DATABASE_URL`. (از Direct connection استفاده نکن؛ Render بهش وصل نمی‌شه.)

جدول‌ها رو خود ربات موقع اجرا می‌سازه.

### ۲. ساخت سرویس توی Render
1. توی render.com با گیت‌هاب وارد شو.
2. بزن **New** ← **Blueprint** و ریپوی `insta-bot` رو انتخاب کن. فایل `render.yaml` خودش یه سرویس رایگان Docker می‌سازه.
3. Render مقدار متغیرها رو ازت می‌پرسه: `TELEGRAM_BOT_TOKEN`، `ADMIN_TELEGRAM_ID`، `IG_USERNAME`، `IG_PASSWORD`، `DM_SENDER_USERNAME`، `DATABASE_URL`. `IG_TOTP_SECRET` اختیاریه و می‌تونی خالی بذاری.
4. **Apply** رو بزن. ساخت اول چند دقیقه طول می‌کشه.

### ۳. بیدار نگه داشتن سرویس
سرویس رایگان Render اگه ۱۵ دقیقه درخواستی نگیره می‌خوابه و ربات از کار می‌افته. برای جلوگیری:
1. آدرس سرویس رو از بالای صفحه‌ی سرویس توی Render بردار (شبیه `https://insta-bot-xxxx.onrender.com`).
2. توی cron-job.org (رایگان) یه Cronjob بساز که هر **۱۰ دقیقه** این آدرس رو باز کنه.

### ۴. اولین ورود
مثل بخش «اولین ورود» پایین‌تر: `/start` بده و کد Authenticator رو با `/code 123456` بفرست.

### محدودیت‌های پلن رایگان Render
- ۷۵۰ ساعت در ماه؛ برای یه سرویس که کل ماه روشنه کافیه.
- حدود ۵ گیگ ترافیک خروجی در ماه. هر ویدیو یه بار برای پیش‌نمایش به تلگرام و یه بار به اینستاگرام فرستاده می‌شه، پس برای چند صد ویدیو در ماه بسنده‌ست، نه بیشتر.
- Render ممکنه هر وقت سرویس رایگان رو ری‌استارت کنه. ربات بعد از روشن شدن خبر می‌ده و سشن اینستاگرام از دیتابیس برمی‌گرده.

## راه‌اندازی روی Railway

### ۱. گذاشتن کد روی GitHub
1. توی GitHub یه ریپوی جدید **Private** بساز (مثلاً `insta-bot`).
2. توی صفحه‌ی ریپو بزن **uploading an existing file** و همه‌ی فایل‌ها و پوشه‌ی `bot` رو بکش و رها کن. بعد **Commit changes**.

### ۲. ساخت پروژه توی Railway
1. توی railway.com بزن **New Project** ← **Deploy from GitHub repo** و ریپوت رو انتخاب کن.
2. Railway خودش `Dockerfile` رو پیدا می‌کنه و می‌سازه. اولین اجرا خطا می‌ده چون هنوز متغیرها رو نذاشتی؛ طبیعیه.

### ۳. اضافه کردن Volume (خیلی مهم)
بدون این، با هر دیپلوی دیتابیس و سشن اینستاگرام پاک می‌شه و ربات هر بار دوباره لاگین می‌کنه (که ریسک قفل شدن رو بالا می‌بره).
- روی سرویس راست‌کلیک کن (یا Ctrl+K) ← **Add Volume** ← Mount path رو بذار: `/data`

### ۴. وارد کردن متغیرها
توی سرویس برو تب **Variables** و این‌ها رو اضافه کن:

| متغیر | چی بذاری |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن جدید از BotFather |
| `ADMIN_TELEGRAM_ID` | آیدی عددی تلگرامت (از @userinfobot) |
| `IG_USERNAME` | یوزرنیم پیج مقصد |
| `IG_PASSWORD` | رمز پیج مقصد |
| `DM_SENDER_USERNAME` | یوزرنیم اکانت شخصی‌ای که ازش ریلز دایرکت می‌کنی |

اختیاری‌ها توی فایل `.env.example` توضیح داده شدن. بعد از ذخیره، Railway خودش دوباره اجرا می‌کنه.

### ۵. اولین ورود
1. توی تلگرام به رباتت `/start` بده.
2. ربات میگه «دارم وارد اینستاگرام می‌شم». چون Google Authenticator روشنه، ازت کد می‌خواد: از اپ Authenticator کد ۶ رقمی رو بردار و بفرست: `/code 123456`
3. اگه اینستاگرام پیام «Was this you?» داد، توی اپ اینستاگرام تأیید کن و بعد توی ربات بزن `/login`.

بعد از این، سشن ذخیره می‌شه و دیگه کد نمی‌خواد مگه اینکه اینستاگرام سشن رو باطل کنه.

## استفاده

| دستور | کار |
|---|---|
| `/add_ig natgeo nasa` | افزودن پیج‌های اینستاگرام |
| `/add_yt @channel` | افزودن کانال یوتیوب (بخش Shorts) |
| `/sources` ، `/remove 3` | لیست و حذف پیج‌ها |
| `/caption متن` | تنظیم کپشن ثابت (`{source}` = اسم پیج مبدأ) |
| `/fetch_posts` | دریافت ویدیوهای جدید و فرستادن برای تأیید |
| `/fetch_stories` | دریافت استوری‌های جدید و فرستادن برای تأیید |
| `/queue` | دیدن صف |
| `/publish 12` ، `/publish all` | انتشار یه آیتم یا کل صف |
| `/check_dm` ، `/dm on/off` | چک فوری دایرکت / روشن‌خاموش کردن چک خودکار |
| `/status` ، `/login` | وضعیت / ورود دوباره |

دکمه‌های پایین صفحه‌ی تلگرام هم همین کارها رو می‌کنن.

## چند نکته برای کم کردن ریسک
- بین هر دو انتشار حداقل ۳ دقیقه فاصله می‌افته و سقف روزانه ۱۵ انتشاره (`PUBLISH_GAP_SECONDS` و `DAILY_PUBLISH_LIMIT`).
- روزهای اول کم منتشر کن تا اکانت به IP سرور عادت کنه.
- اگه اینستاگرام گفت «Feedback required» یا «Please wait»، چند ساعت دست نگه دار.
- ویدیوهای بلندتر از ۳ دقیقه رد می‌شن (`MAX_VIDEO_SECONDS`).
- اگه یوتیوب خطای «Sign in to confirm you're not a bot» داد، `YT_COOKIES` یا `YT_PROXY` رو تنظیم کن.
